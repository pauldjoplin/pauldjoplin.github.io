# Lucid Grove Studio Capstone ePortfolio

This repository contains my senior capstone ePortfolio for the Computer Science program. The selected artifact for this capstone is my existing Lucid Grove Studio website, which will be enhanced to demonstrate growth in software design and engineering, algorithms and data structures, and databases.

## Project Purpose

The purpose of this capstone is to enhance an existing professional website into a more modular, interactive, and data-driven web application. The project focuses on meaningful technical improvements rather than visual redesign alone.

## Selected Artifact

The artifact selected for this project is the Lucid Grove Studio website. The current site functions as a professional business and portfolio website. For the capstone, I will preserve the original version and create an enhanced version that demonstrates stronger software architecture, algorithmic functionality, and database integration.

## Planned Enhancements

### 1. Software Design and Engineering

The website will be refactored into reusable React components. This will improve maintainability, reduce repeated code, and make the project easier to expand in the future.

Planned improvements include:

- Reusable React components
- Cleaner page structure
- Shared layout components
- Structured service and project data
- Improved code readability
- Better documentation and comments

### 2. Algorithms and Data Structures

The project starter and pricing flow will be enhanced into an interactive recommendation and example estimate system. Users will be able to select project needs, and the system will use structured data and scoring logic to recommend a service path.

Planned logic may include:

- Weighted scoring
- Filtering
- Sorting
- Conditional recommendations
- Example estimate generation
- Optional inquiry message generation

### 3. Databases

The site will include a database-backed service and pricing catalog. This database will store non-sensitive business content such as services, package options, pricing ranges, add-ons, and estimated effort values.

This approach demonstrates database functionality while avoiding unnecessary storage of personal customer inquiry data.

## Privacy and Security Approach

This project is designed with a privacy-conscious approach. The database enhancement will focus on public-facing service and pricing data rather than storing unnecessary customer inquiry information.

Sensitive information such as environment variables, API keys, private deployment settings, customer information, and business-sensitive files will not be included in this public repository.
