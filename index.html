Course Outcome Alignment

The completed artifact enhancements collectively demonstrate the five Computer Science capstone outcomes. Each enhancement contributes to more than one outcome, and together they show growth across technical implementation, communication, decision-making, and security.

Outcome 1: Collaborative Environments and Decision Making

The Project Builder supports decision-making for nontechnical users by guiding them through service options, support paths, and project needs in an organized and understandable way.

Outcome 2: Professional Communication

The narratives, documentation, code review videos, and ePortfolio presentation communicate technical work to both technical and nontechnical audiences.

Outcome 3: Algorithms and Computer Science Practices

The enhanced Project Builder uses structured data, mapping, conditional logic, grouped recommendations, and design trade-off management to solve a real service-selection problem.

Outcome 4: Software Engineering Tools and Techniques

The reusable React components, backend-supported service data, API integration, and maintainable project organization demonstrate industry-relevant development practices.

Outcome 5: Security Mindset

The enhanced artifact avoids unnecessary customer data storage, separates backend configuration from public code, uses example configuration files instead of real secrets, and supports privacy-conscious design.
