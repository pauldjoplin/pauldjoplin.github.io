Project Overview

This ePortfolio will document my senior capstone project for the Computer Science program. The project focuses on improving an existing real-world website into a more modular, interactive, and data-driven web application.

Selected Artifact

My selected artifact is the existing Lucid Grove Studio website. The current site functions as a professional business and portfolio website. For the capstone, I will enhance this single artifact across the three required computer science categories.

Planned Enhancements

Software Design and Engineering

Refactor the website into reusable React components to improve maintainability, reduce repeated code, and create a stronger internal structure.

Algorithms and Data Structures

Enhance the project starter and pricing flow into an interactive recommendation and example estimate system using structured data, scoring logic, filtering, and conditional rules.

Databases

Add a database-backed service and pricing catalog that stores non-sensitive business data, such as services, add-ons, pricing ranges, and estimated effort values.

Skill Set and Career Focus

This ePortfolio will demonstrate my skills in web development, software engineering, database integration, algorithmic problem-solving, professional communication, and privacy-conscious design.

My career focus is software and web development, especially building practical, user-centered applications for small businesses.
